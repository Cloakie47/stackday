For developers

Architecture

Solidity contracts on Base Sepolia hold and move all money. A Next.js app on Vercel reads the chain, asks your wallet to sign, and runs a few server routes for accounts, chat, research and the trigger bot.

{{PLAIN}}

There are two halves. The blockchain half is a set of small programs (smart contracts) that hold the money and follow fixed rules. The website half shows you what is going on and prepares transactions, but it can never move your money by itself: your wallet has to sign.

Design principles

  • Adapters everywhere. Swaps, lending, prices and interest go through adapter interfaces, so moving from a mock to the real thing is a configuration change. Testnet uses the mock exchange; mainnet uses SlipstreamSwapAdapter on Aerodrome. Lending uses MorphoLendingAdapter, one per market.
  • No lending pool of our own. Loans come from existing Morpho markets.
  • Ownerless core. Payroll, SipRouter, GiftBox, VaultFactory, the vaults and the adapters have no owner. Only the testnet mocks have one, on purpose.
  • The site works without servers. With no database or model keys, money features keep working; names, teams, chat and live research switch off or show labelled samples.
  • Simulate before signing. web/lib/useTx.ts simulates each transaction and adds a 60% gas margin, because Morpho interest accrual makes real gas use higher than estimates.
  • Mock to real, proven by fork tests. test/fork/ runs the same code against real AAPLc, a real Aerodrome pool, the real Morpho markets (including deSPXA) and a real Morpho interest vault on a copy of Base mainnet.

Run it locally

git clone --recurse-submodules https://github.com/Cloakie47/stackday.git
cd stackday
forge test                      # local contract tests
cd web
npm install
npm run dev                     # http://localhost:3000, reads the testnet deployment
npm test                        # web unit tests (Node 22.18 or later)

Fork tests: $env:FOUNDRY_PROFILE="fork"; forge test (Foundry 1.8.4 or later). After a redeploy: forge build, then python web/scripts/gen-abis.py. Read web/AGENTS.md before changing Next.js structure: this Next.js version differs from older ones.
