Deploying your own copy

Never overwrite the official deployments/base-sepolia.json. To deploy a copy for testing, set DEPLOYMENTS_FILE=deployments/local-yourname.json and run forge script script/Deploy.s.sol --rpc-url base_sepolia --broadcast --slow --gas-estimate-multiplier 150 with a test-only wallet. It needs about 36 test USDC to fund the markets and a little test ETH. Scripts that touch Morpho need a gas margin, because simulations see no interest accrual.
